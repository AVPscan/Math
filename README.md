# Math Library

*Библиотека для работы с целыми числами произвольной точности*

## Философия

В основе библиотеки лежат древние термины на санскрите:

- **As** (अः) — основа, бытие, существование
- **anu** (अणु) — атом, наименьшая частица
- **an** (अङ्क) — цифра, число
- **nimitta** (निमित्त) — знак, признак
- **vṛddhi** (वृद्धि) — увеличение, рост
- **vikāra** (विकार) — модификация, изменение состояния

Каждое число рассматривается как последовательность атомов (*anu*), где каждый атом — это байт. Библиотека оперирует с числами от 1 до 255 атомов, что даёт диапазон от 8 до 2040 бит.

Библиотека использует представление числа `BigEndian` расположенные в памяти от старшего к младшему, а функция `FBSWAP` служит мостом между представлением библиотеки и миром от младшего к старшему.

### Функции

`FBSWAP` Переворот байт `Eb<>Be`

`FMOVB`  Преобразование байта

`FVMOVB` Преобразование двух байт

`FRR`    Перенос > сдвиг вправо > перенос

`FRL`    Перенос < сдвиг влево < перенос

`VIKARA` Изменение разрядности

`FADD`   Сложение

`FSUB`   Вычитание

`FMUL`   Умножение двойная разрядность

`FDIV`   Деление

`FVDIV`  Деление двойная разрядность

### Состояние

`Mat.Nim`   Представление числа > 0 — беззнаковое, Иначе — знаковое

`Mat.Long`  Пользовательская переменная > размер в байтах 

`Mat.Carry` Флаг переноса > Только в беззнаковом представлении чисел, ибо бесконечности там нет

`Mat.Riz`   Состояние результата >   0 - число,       1 ноль/бесконечность

`Mat.Rnim`  Состояние результата > 0/0xFF - знак, 0 - ноль 0xFF - бесконечность
